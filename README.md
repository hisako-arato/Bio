# 黄昏の村

ブラウザで遊べる、肩越し視点のサバイバルホラー。スマホ（横向き）と PC の両方で動く。今は第2章まで（1章あたり約10分）。

公開ページ：https://hisako-arato.github.io/Bio/

## 章

### 第1章 黄昏の村
1. **村はずれの小道**：移動・構え・撃つ・蹴るを覚えながら広場へ（ゾンビ5体）
2. **村の広場**：入口が閉ざされ、鐘が鳴るまで（1分50秒）生き延びる。西の家の軒下にショットガン
3. **北の路地**：鐘が鳴るとゾンビは去り、北の門が開く。路地の商人で弾・ハーブ・改造を買える
4. **教会の前庭**：大男（ボス）と手下。突進を壁にぶつけさせると怯むので蹴る。倒して教会の扉へ

### 第2章 沈黙の教会
1. **礼拝堂**：祭壇の鍵を取ると側面の扉が破られ、襲撃が始まる（9体）。退けると祭壇の奥の扉が開く
2. **地下墓所**：暗い迷路。懐中電灯が向いている方を照らす。床を這うゾンビ（蹴っても倒れない、ナイフがよく効く）。封印の石碑を3つ調べると奥の扉が開く。入口に商人
3. **納骨堂**：墓守（ボス）と、這うゾンビの手下。四本の柱に突進をぶつけさせて蹴る。倒すと出口が開く

- 章をクリアすると結果（時間・命中率・やられた回数でランク）が出て、次の章へ進める
- やられたら、その区画の入口からやり直せる（持ち物はそこに着いたときのもの）
- 区画に着くたびに端末へセーブする。タイトルの「つづきから」で続きを遊べる
- 拾ったファイルは、一時停止の「ファイル」で読み返せる

## 物語の肉付け（js/story.js）

物語の文言は、すべて `js/story.js` にまとめてある。ゲームの仕組みに触れずに書き換えられる。【仮】の付いた文が、物語が決まったら書き換える場所。

| 名前 | 中身 |
|---|---|
| `CHARACTERS` | 話し手の名前（主人公・商人・謎の声など） |
| `CHAPTERS` | 章の題名・始まりの文・目的・クリア時の一言 |
| `OBJECTIVES` | 画面の上に出る目的の文 |
| `SCENES` | 会話の場面。1行は `[話し手, 台詞]`（話し手が `null` なら地の文）。行は足しても消してもよく、`[]` にするとその場面は飛ばされる |
| `FILES` | 拾って読める文書（題名と本文） |

会話の場面が流れる所（`js/chapters/` の `say('場面の名前')`）：

| 場面 | いつ |
|---|---|
| `ch1_start` | 第1章の始め |
| `ch1_siege` | 広場で囲まれたとき |
| `ch1_bell` | 鐘が鳴った後 |
| `ch1_merchant`／`ch2_merchant` | その章で初めて商人に話しかけたとき |
| `ch1_boss` | 大男が現れたとき |
| `ch1_end` | 教会の扉に着いたとき（第1章の終わり） |
| `ch2_enter` | 礼拝堂に入ったとき |
| `ch2_altar` | 祭壇の鍵を取ったとき（この後に襲撃） |
| `ch2_ambush_end` | 襲撃を退けたとき |
| `ch2_crypt` | 地下墓所に降りたとき |
| `ch2_seal_done` | 最後の石碑を調べたとき |
| `ch2_boss` | 墓守が現れたとき |
| `ch2_end` | 出口に着いたとき（第2章の終わり） |

ファイルの置き場所：`f_memo`（第1章の小道）、`f_villager`（第1章の北の路地）、`f_priest`（第2章の説教台）、`f_crypt`（第2章の地下墓所）。置き場所を変える・足すときは各章の `setup()` の `dropItem('file', 'ファイルの名前', x, z)`。

新しい章を足すときは、`js/chapters/ch2.js` を手本に `ch3.js` を作り、`js/game.js` の `CHAPTER_LIST` に足して、前の章の `next` を `'ch3'` にする。地図は `js/world2.js` のように別のファイルで、離れた場所（x や z をずらす）に作る。

## 操作

| | スマホ | PC |
|---|---|---|
| 移動 | 画面の左側をなぞる（大きく倒すと走る） | WASD／矢印、Shift で走る |
| 視点 | 画面の右側をなぞる | マウス（画面をクリックで操作開始） |
| 構える | 「構え」で切り替え | 右クリックを押している間 |
| 撃つ | 「撃つ」（押したまま指を動かすと狙いも動く） | 左クリック |
| 弾込め／ナイフ／持ち替え／回復 | 各ボタン | R／F／Q／H |
| 蹴る・話す・掴まれたら連打 | 出てくるボタン | E／Space |
| 一時停止 | 右上の Ⅱ | Esc |

- 脚を撃つとひざをつき、頭を撃つとひるむ。ひるんだ敵は蹴り飛ばせる（周りもまとめて）
- 倒れた敵にはナイフがよく効く。木箱と樽は撃つかナイフで壊すと中身が出る
- スマホでは「狙いの補助」が初めから有効（構えた瞬間に近くの敵へ寄り、照準が敵の上では動きが重くなる）。設定で切り替えられる
- 設定：視点の感度・上下反転・狙いの補助・血の表現（多い／少ない／なし）・画質・音量

## 作り

- 3D 描画に [Three.js](https://threejs.org/) r170、VRM の読み込みに [three-vrm](https://github.com/pixiv/three-vrm)（どちらも MIT License）を `vendor/` に同梱
- ビルドは不要。静的ファイルをそのまま置けば動く（GitHub Pages で公開）
- 音はすべて Web Audio で合成している（音のファイルは無い）
- 背景（村・家・教会・木）は `js/world.js` でプログラムから組み立てる。動かない物は材質ごとに1つの形へまとめ、木は同じ形をまとめて描く（描く回数を減らす）
- 画質「軽い」（スマホの既定）は解像度を抑え、影を描かない。「きれい」（PC の既定）は建物の影を最初に一度だけ描く

### キャラクター（VRM）

| ファイル | 内容 |
|---|---|
| `assets/vrm/player/black.vrm` | 主人公。Oyashiki の `assets/vrm/lite/black.vrm`（テクスチャ512px）をそのまま使う。髪とスカートは揺れる |
| `assets/vrm/zombie/z_*.vrm` | ゾンビ6種。Oyashiki の VRM から `tools/vrm_zombie.py` で作った（約2.5〜3.8MB） |

ゾンビは種類ごとに1体だけ読み込み、形と画像を共有したまま骨だけを複製して何体も出す（`js/vrm.js` の `cloneZombie`）。材質は場面の光を受ける軽いもの（Lambert）に置き換え、輪郭線と揺れものは使わない。画面に映らないゾンビは姿勢の計算を止め、遠いゾンビは2〜3フレームに1回だけ姿勢をつける。

| ゾンビ | 元の VRM | 特徴 |
|---|---|---|
| `z_m1` | Oyashiki `guest/guest_m1` | 両腕を前に伸ばす。普通 |
| `z_m2` | Oyashiki `guest/guest_m2` | 腕を垂らす。普通 |
| `z_father` | Oyashiki `lite/father` | 遅いが硬い |
| `z_f1` | Oyashiki `guest/guest_f1` | 速い・もろい |
| `z_f2` | Oyashiki `guest/guest_f2` | やや速い |
| `z_brute` | Oyashiki `lite/guard` | 大男（1.38倍に拡大）。突進・振り下ろし |

第2章では同じ VRM を使い回して、床を這うゾンビ（`z_m2`・`z_f1` を前に倒して腕で進む）と、墓守（`z_father` を1.45倍）を出している。

ゾンビの VRM を作り直す／足すとき（Pillow と NumPy が要る）：

```
python3 tools/vrm_zombie.py 元.vrm assets/vrm/zombie/z_new.vrm --skin green --seed 7
```

`--skin`（green／gray／purple）で肌の色、`--seed` で汚れと血の付き方、`--blood` で血の量を変える。肌・目・服・髪の画像を VRoid の材質名で見分けて塗り替え、表情と揺れものを取り除き、`tools/vrm_lite.py` で画像を256pxまで縮める。新しい種類は `js/zombies.js` の `TYPES` に足す。

動きはモーションのファイルを使わず、`js/anim.js` で骨の角度をプログラムでつけている（歩く・走る・構える・弾込め・ナイフ・蹴り・回復・掴まれる・倒れる／ゾンビの徘徊・振りかぶり・掴み・ひるみ・ひざつき・雄叫び）。

## ローカルで動かす

```
python3 -m http.server 8000
```

で `http://localhost:8000/` を開く（ファイルを直接開くと VRM を読み込めない）。

動作確認用に、コンソールから `__game` を使える：`__game.jump('ch1', 'plaza')`（第1章は `path`／`plaza`／`lane`／`yard`、第2章は `nave`／`crypt`／`ossuary` へ飛ぶ）、`__game.sim(5)`（描画せずに5秒進める）。
